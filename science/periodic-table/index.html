    How to Use It

    Explore
    Tap any element to see its number, what kind it is, where it sits, and what it's used for. Nothing is being marked — have a wander.
    Easy
    Three choices. Sometimes you see He and pick Helium; sometimes you see Helium and pick He. The wrong answers are always real elements from nearby, so it's a proper choice rather than a giveaway.
    Medium
    No choices — type the answer yourself. Capital letters and spaces don't matter, so "helium" is fine.
    Hard
    Type the symbol and tap the square it belongs in. The table is blanked out until you've typed, so you're finding the place from memory rather than reading it off.
    Which elements?
    Start with the Common 20 — hydrogen through calcium, the ones that actually turn up in life. Then the first 36, then all 118 when you're feeling brave.
    Reading the table
    Elements are in order of how many protons they have, left to right and top to bottom. Columns matter: everything in a column behaves in a similar way. That's why the far right are all gases that do nothing, and the far left all react like mad.
    The two rows underneath
    Those aren't separate — they belong in the gaps marked 57–71 and 89–103. They're pulled out so the table fits on a page instead of being enormously wide.
