Making someone an account

Not from here
Creating a login needs a key that can bypass every security rule in the database, and a key like that must never be in a web page. So new accounts are made in the Supabase dashboard, under Authentication → Users → Add user, and a member row here is linked to it afterwards.
A member is not a login
You can list somebody as a member without them ever having an account — useful for a child whose parent would rather they did not sign in to anything.
